# Estacionamento

## Projeto para aplicação local 
Este projeto é uma aplicação que gerencia vagas de estacionamento de estabelecimentos

## Objetivo 
Contabilizar quantidade de vagas, disponibilidade, tempo de permanencia do usuário e gerar a cobrança do tempo de permanencia

## Tecnologias 
.NET
Angular
MariaDB

Obs.: Este projeto ainda está na fase de desenvolvimento, este repostório será o prototipo da aplicação.
